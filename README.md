# Django Store

Тестовое задание на позицию Python/Django Intern.

Простой интернет-магазин, реализованный на Django с серверным рендерингом через Django Templates. Пользователи могут просматривать каталог товаров, добавлять товары в корзину, оформлять заказы и регистрировать аккаунты с подтверждением электронной почты.

## Функциональность

### Каталог товаров

* Просмотр списка товаров
* Просмотр детальной информации о товаре
* Отображение названия, описания, цены и изображения

### Корзина

* Добавление товаров в корзину
* Изменение количества товаров
* Просмотр содержимого корзины
* Подсчет общей стоимости заказа

### Заказы

* Оформление заказа без обязательной авторизации
* Ввод имени клиента и номера телефона
* Сохранение заказа и позиций заказа в базе данных

### Пользовательские аккаунты

* Регистрация пользователя
* Авторизация и выход из системы
* Подтверждение электронной почты
* Отправка письма подтверждения в фоновом потоке

### Административная панель

* Создание товаров
* Редактирование товаров
* Удаление товаров
* Просмотр заказов
* Просмотр состава каждого заказа

## Архитектура проекта

### Product

Хранит информацию о товаре:

* id
* name
* description
* price
* image

### Order

Хранит информацию о заказе:

* id
* customer_name
* phone_number
* created_at

### OrderItem

Связывает заказ с товарами:

* id
* order_id
* product_id
* quantity

Корзина хранится в Django Session до момента оформления заказа.

## Локальный запуск

### Через Docker

```bash
docker compose up --build
```

После запуска приложение доступно по адресу:

http://localhost:8000

### Административная панель

```bash
docker compose exec web python manage.py createsuperuser
```

Админка:

http://localhost:8000/admin/

## Email Confirmation

Для реальной отправки писем через Gmail необходимо создать файл `.env`.

Пример:

```env
EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=1
EMAIL_HOST_USER=your_email@gmail.com
EMAIL_HOST_PASSWORD=your_app_password
DEFAULT_FROM_EMAIL=your_email@gmail.com
```

Используется Google App Password.
